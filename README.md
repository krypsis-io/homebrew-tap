# Homebrew Tap

Homebrew formulae for [Krypsis](https://github.com/krypsis-io) tools.

## Install

```bash
brew install krypsis-io/tap/wick
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [wick](https://github.com/krypsis-io/wick) | Fast, zero-config secret and PII redaction for any text stream |
